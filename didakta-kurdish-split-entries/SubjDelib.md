# §SubjDelib. ڕاوێژکاری

کرداری داخوازی ڕاوێژکاری(ئیستا یان ڕابردوو) گومانی قسەکەر دەرئەبڕێت کە بڕیارە چی بکات. ئەم بەکارهێنانە ئیلتزامی لەگەڵ [μή](https://logeion.uchicago.edu/%CE%BC%CE%AE) دەبێتە نه‌رێنی و بەگشتی لە هه‌وه‌ل کەسدا دێت.  
→ “[**εἴπωμεν**](https://logeion.uchicago.edu/%2A%2A%CE%B5%E1%BC%B4%CF%80%CF%89%CE%BC%CE%B5%CE%BD%2A%2A) [ἢ](https://logeion.uchicago.edu/%E1%BC%A2)/pwmen) [**σιγῶμεν**](https://logeion.uchicago.edu/%2A%2A%CF%83%CE%B9%CE%B3%E1%BF%B6%CE%BC%CE%B5%CE%BD%2A%2A)%5C);” [**E. Ion 758**](https://www.perseus.tufts.edu/hopper/text?doc=Eur.%20Ion%20758&lang=original); ⇾   
«قسە بکەین یان بێدەنگ بین؟»  
→ “[τί](https://logeion.uchicago.edu/%CF%84%CE%AF) [**δράσω**](https://logeion.uchicago.edu/%2A%2A%CE%B4%CF%81%CE%AC%CF%83%CF%89%2A%2A); [ποῖ](https://logeion.uchicago.edu/%CF%80%CE%BF%E1%BF%96) [**φύγω**](https://logeion.uchicago.edu/%2A%2A%CF%86%CF%8D%CE%B3%CF%89%2A%2A);” [**E. Med. 1271**](https://www.perseus.tufts.edu/hopper/text?doc=Eur.%20Med.%201271&lang=original); ⇾   
«چی بکەم؟ بۆ کوێ هەڵێم؟»  
→ “[μὴ](https://logeion.uchicago.edu/%CE%BC%E1%BD%B4) [**φῶμεν**](https://logeion.uchicago.edu/%2A%2A%CF%86%E1%BF%B6%CE%BC%CE%B5%CE%BD%2A%2A);” [**P. R. 554b**](https://www.perseus.tufts.edu/hopper/text?doc=Plat.%20Rep.%20554b&lang=original); ⇾   
«نه‌ڵێین؟»  
پرسیاری داخوازی ئاماژە بە ڕاستییەکی داهاتوو ناکات، بەڵکو ئاماژە به کردارێک دەکات کە لە دۆخی ئێستادا باش یان گونجاوە. بەگشتی پێش له کرداری داخوازی [βούλει](https://logeion.uchicago.edu/%CE%B2%CE%BF%CF%8D%CE%BB%CE%B5%CE%B9) و [βούλεσθε](https://logeion.uchicago.edu/%CE%B2%CE%BF%CF%8D%CE%BB%CE%B5%CF%83%CE%B8%CE%B5) (لە شیعردا [θέλεις](https://logeion.uchicago.edu/%CE%B8%CE%AD%CE%BB%CE%B5%CE%B9%CF%82) و [θέλετε](https://logeion.uchicago.edu/%CE%B8%CE%AD%CE%BB%CE%B5%CF%84%CE%B5)) دێت.  
→ “[βούλει](https://logeion.uchicago.edu/%CE%B2%CE%BF%CF%8D%CE%BB%CE%B5%CE%B9) [σοι](https://logeion.uchicago.edu/%CF%83%CE%BF%CE%B9) [**εἴπω**](https://logeion.uchicago.edu/%2A%2A%CE%B5%E1%BC%B4%CF%80%CF%89%2A%2A);” [**P. G. 521d**](https://www.perseus.tufts.edu/hopper/text?doc=Plat.%20Gorg.%20521d&lang=original); ⇾   
«ده‌ته‌وێ بۆت باس بکەم؟»
